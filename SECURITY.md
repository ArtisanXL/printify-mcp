# Security Policy

## Supported Versions

Only the latest released version of `@artisanxl/printify-mcp` receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue. Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/ArtisanXL/printify-mcp/security/advisories/new).

You can expect an initial response within 7 days. Never include real Printify API tokens
in reports.
